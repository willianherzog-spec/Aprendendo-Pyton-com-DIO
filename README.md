# Aprendendo-Pyton-com-DIO
Repositório publico para treinamento utilizando Notebook LM, para iniciar a aprendizagem com python.
O tema utilizado foi como um iniciante pode utilizar as ferramentas de inteligência artificial para iniciar a aprendizagem em python, criando um resumo inicial e depois um plano detalhado para aprendizagem.
Crie um resumo sobre os conceitos fundamentais de pensamento computacional, como são os primeiros passos para utilizar Python e como utilizar os copilotos (ia) para auxiliar na aprendizagem de programação.
